## 📋 Rasmlar talablari:

### Umumiy talablar:
- **Format**: JPG (tavsiya etiladi) yoki PNG
- **Sifat**: Yuqori sifat (min 1920x1080px yoki undan yuqori)
- **Og'irlik**: Optimallashtirilgan (max 500KB har bir rasm)
- **Rang rejimi**: RGB
- **Fayl nomlari**: Kichik harflar, tire (-) bilan, masalan: `hero-students.jpg`

### Aspect Ratio (nisbat):
- **Hero**: 16:9 yoki 4:3
- **Countries**: 16:9
- **Testimonials**: 16:9
- **Certificates**: 3:4 yoki 4:3
- **About**: 16:9 yoki 4:3
